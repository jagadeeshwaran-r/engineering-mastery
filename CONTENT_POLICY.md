# Public Content & Copyright Policy

[← Home](README.md)

This repository is meant to be a public **annotated technical reading library**. Public access does not imply that every file may legally be shared.

## Current inventory disclosure

The current public repository contains **16 PDF uploads** alongside the catalog and Markdown reading guides. The distribution rights for those PDFs **have not been verified**. They should not be assumed to be openly licensed, even if a file is technically accessible.

**Owner action required:** review each upload against its license or the publisher/author's permission. Files without redistribution rights should be removed from the public branch **and purged from Git history** (ordinary deletion does not remove earlier accessible commits). Consider keeping personal copies in private, lawful storage instead.

## Rules for future contributions

- Prefer book metadata, publisher links, lawful open-access sources, and original notes.
- Do not add copyrighted textbook PDFs, scans, or substantial excerpts without clear public redistribution permission.
- Cite sources and write original explanations; do not reproduce copyrighted chapters or solutions.
- Do not publish confidential data, credentials, or private documents.
- No project-wide license has been selected. Public readability is not a license to reuse the original notes.

The educational descriptions in this repository explain **curatorial purpose**; they are not claims of permission, ownership of the books, or full-text book reviews.
