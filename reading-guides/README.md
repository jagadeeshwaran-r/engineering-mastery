# Book Reading Guides

[← Home](../README.md) · [Catalog](../CATALOG.md) · [Start here](../START_HERE.md)

Every guide answers **why this reference is here**, **what to focus on**, and **how to apply it**. These are short orientation notes, not reproductions or summaries of the PDF contents.

**16 catalog entries correspond to 14 guides**, because three entries refer to different editions or file versions of the same *Computer Systems: A Programmer's Perspective* title.
