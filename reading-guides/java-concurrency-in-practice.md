## Why this book is here

Builds disciplined reasoning about Java thread safety and shared state. It supports the larger goal of shared state and system behavior.

## What to look for

- Synchronization
- Safe publication
- Executors
- Concurrency hazards

## How to approach it

Read with an application in mind. Write a brief original explanation of **synchronization, safe publication, executors, concurrency hazards**, then test that understanding with the exercise below.

## Put it into practice

Implement and test a small thread-safe component; document its invariants.
