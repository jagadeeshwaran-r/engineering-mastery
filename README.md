## About this library

Engineering Mastery is a public **reading catalog and study-notes repository** organized around the subjects that make strong software engineers. It records books and technical references, connects them to important concepts, and provides space for original notes.

**Current snapshot:** 8 collections · 16 references identified from the initial collection · an AI shelf ready to grow.

> **Books are not hosted here.** This repository contains bibliographic references and original study materials, not third-party book PDFs or unauthorized copies. See [Content & copyright policy](CONTENT_POLICY.md).

## Recommended learning sequence

1. **Build foundations:** mathematics, logic, and discrete mathematics.
2. **Strengthen reasoning:** problem-solving methods and data structures and algorithms.
3. **Understand production systems:** architecture, performance, and concurrency.
4. **Design thoughtfully:** clean code, software architecture, and engineering trade-offs.
5. **Explore AI:** connect mathematics and programming with machine learning.

This is a suggested route, not a prerequisite chain. See [LEARNING_PATH.md](LEARNING_PATH.md) for practice ideas.

## How to use this repository

- **Browse** the [catalog](CATALOG.md) to see titles, authors, editions, and reading status.
- **Study** by adding your original Markdown notes in the appropriate subject folder.
- **Track progress** using `Not tracked`, `To read`, `Reading`, `Completed`, or `Revisit`.
- **Contribute** with corrections and suggestions following [CONTRIBUTING.md](CONTRIBUTING.md).

## Principles

- **Signal over volume:** curate for purpose, not quantity.
- **Deep understanding:** explain concepts, examples, limits, and trade-offs.
- **Practical application:** connect reading to Java and real-world systems.
- **Respect authors:** cite sources and do not publish unauthorized copies of books.
