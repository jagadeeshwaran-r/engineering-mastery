## What is this?

**Engineering Mastery** explains *which technical books are worth studying, why they belong together, and what a reader can learn from each one.* It is a curated personal engineering library—not a course, certification, or claim that every book has been completed.

The catalog currently records **16 file entries**, including multiple editions of the same systems textbook, across **8 subject shelves** (the AI shelf is being developed).

## How to read this library

1. Choose a collection or learning path.
2. Read its **why this category exists** explanation.
3. Follow a title's **reading guide** for the purpose, recommended focus, and a practical exercise.
4. Write your own notes and record your progress; all current statuses are **Not tracked**.
5. Use books as references, not as a checklist to finish every page.

See the [reader's orientation](START_HERE.md) for details.
