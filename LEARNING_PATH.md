# Learning Path

[← Home](README.md) · [Catalog](CATALOG.md)

A flexible progression from mathematical fundamentals to software engineering and AI. No prior proficiency or completion is assumed.

| Stage | Read from | Goal | Practice suggestion |
|---|---|---|---|
| 1. Mathematical fundamentals | [Foundational Mathematics](01_Foundational_Math/README.md) | Understand functions, algebra, and calculus | Work examples by hand and explain each step |
| 2. Rigorous thinking | [Logic & Discrete Mathematics](02_Logic_and_Discrete_Math/README.md) | Construct clear arguments and proofs | Prove one claim in two different ways |
| 3. Problem-solving habits | [Problem Solving](03_Problem_Solving/README.md) | Decompose unfamiliar problems | Maintain a personal problem journal |
| 4. Algorithmic fluency | [Data Structures & Algorithms](04_Data_Structures_Algorithms/README.md) | Reason about correctness and complexity | Implement in Java, including edge cases |
| 5. Understanding systems | [Systems & Architecture](05_Systems_Architecture/README.md) | Understand memory, storage, networks, and reliability | Trace one request through a service |
| 6. Concurrency & performance | [Performance & Concurrency](06_Performance_Concurrency/README.md) | Reason about synchronization and measurement | Benchmark a small concurrent Java program |
| 7. Engineering design | [Clean Code & Design](07_Clean_Code_Design/README.md) | Make deliberate design/refactoring choices | Refactor a project and document trade-offs |
| 8. AI foundations | [Artificial Intelligence](08_Artificial_Intelligence/README.md) | Connect mathematics and programming to ML | Implement a simple model and evaluate it |

## Reusable study method

1. **Preview** the problem a chapter is addressing.
2. **Read actively** and write down questions.
3. **Reconstruct** its ideas without looking at the text.
4. **Apply** with a proof, implementation, or worked exercise.
5. **Review** your original notes later and correct misunderstandings.

This path is non-linear. Return to earlier topics as needed.
